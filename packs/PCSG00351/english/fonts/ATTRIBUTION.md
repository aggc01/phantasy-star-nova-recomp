# Glenth Regular

The English text, UI lettering and movie subtitles are drawn with **Glenth Regular 1.004** (`glenthregular.ttf`) by
OWPictures. The font file's name table lists OWPictures as the designer and carries the notice
`OWPIctures - All rights reserved`. It is not part of this repository, and you need your own copy.

[Glenth by OWPictures](https://elements.envato.com/glenth-classic-display-serif-font-9ZK6SWW)

## Adding your copy

1. Get Glenth Regular under a license that covers your use, and keep the license it comes with.
2. Copy the TrueType file `glenthregular.ttf` into this folder (`packs/PCSG00351/english/fonts/`). Git ignores font
   files here, so it is never committed.
3. Run `vitarecomp localize PCSG00351`, or add the game as the README describes: the English is then built on its own.

A different Glenth build works too. If it is not the file the English layout was checked with (SHA-256
`eb9bf6e6c482e82307a6b505c58a3e70499c137dfddb98c7a53fc404d3745e0f`), the build says so and continues, and text spacing
may differ slightly.

The font is only read while the English text, UI art and subtitles are built on your PC. What it draws stays in your
`dump` folder.
