# Nova PC overlay layout

24 November 2026.

The F10 overlay, save picker, and character-name editor use the Project Nativ dark palette with viewport-scaled typography and spacing. The layout changes live in `runtime/ui/overlay.cpp` and `runtime/ui/ui_theme.h`.

- **F10 menu**. Wide windows use a section rail and narrow windows use a two-row section bar. Settings scroll inside their section while Resume, Capture frame, and Quit stay visible. Each section has its own scroll state. Controller shoulder buttons and Ctrl+Tab still switch sections. Choice buttons wrap within their settings column. Quit opens the existing confirmation.
- **Save picker**. Each card gives the character name priority over the class, level, playtime, and chapter. The slot number, timestamp, and Delete action sit together on the right. The formatter splits from the right so names can contain slashes, and legacy metadata has a fallback. The delete confirmation identifies the slot and starts on Cancel. Backups are available in F10 → Saves.
- **Character name**. A larger PC text field and a controller keyboard use the same panel styling. The editor keeps the character count and Confirm/Cancel controls visible. A / Cross selects a key and Start confirms on a controller.
